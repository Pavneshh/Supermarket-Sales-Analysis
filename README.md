# Supermarket Sales Analysis

## Overview
This project analyzes supermarket sales data using Python, Pandas, Matplotlib, and Streamlit.

## Features
- Sales Trend Analysis
- Hourly Sales Analysis
- Discount Impact Analysis
- Category-wise Sales Analysis
- Interactive Dashboard

## Technologies Used
- Python
- Pandas
- Matplotlib
- Streamlit

## Dataset
Supermarket Sales Dataset (4 CSV files merged and cleaned)

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
